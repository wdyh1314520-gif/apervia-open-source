## Apervia 1.0.1 已准备就绪

本次更新让公开版本与当前 Docker 使用体验保持一致，进一步完善双语覆盖、精简认证运行时，并改进部署说明。

### 本次改进

- **完整语言切换**：登录、设置、活动、思考过程、MCP、版本公告及后台界面都会跟随应用内选择的语言。
- **精简认证运行时**：公开应用已删除旧 SMTP、邀请码、可编辑法律文档、本地令牌和旧后台入口。
- **清晰部署流程**：教程补充正确克隆目录、Sandbox 镜像拉取、完整 CI 检查和当前英文界面截图。
- **更安静的默认行为**：删除启动网址宣传、旧第三方默认接口和未使用的语音预设。
- **版本检查**：账号设置可通过官方 GitHub Release 信息检查是否存在新版本。

### 升级说明

- 升级前请备份 `apervia_app3_data` 数据卷。
- 将 App 与 Sandbox 镜像版本同时更新为 `1.0.1`，再一并拉取并重建服务。
- Chat Completions 与 Responses 继续保持独立，不会混用已有配置。
- 点击**我知道了**后，本账号将确认此版本；仅关闭公告只会在当前页面临时隐藏。
