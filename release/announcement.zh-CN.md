## 欢迎使用 Apervia 1.0.0

这是 Apervia 的首个正式版本。它将对话、文件、知识库、联网搜索、MCP 工具与隔离沙盒整合到同一个工作空间中，并为 Docker 部署提供完整的账号与运维体系。

### 本次发布内容

- **统一工作空间**：集中管理普通对话、临时聊天、附件、生成文件与长期知识库。
- **独立 API 模式**：分别配置和运行 Chat Completions 与 Responses，两种协议互不干扰。
- **MCP 集成**：提供服务端 MCP 目录、OAuth 授权、加密凭据和权限分级。
- **安全沙盒**：通过独立 Sandbox Runner 执行代码和文档任务，默认关闭网络、只读根文件系统并使用最小权限。
- **账号与数据管理**：提供注册审核、角色、会话、备份、审计和存储治理能力。
- **生产容器交付**：提供版本一致的多架构 App 与 Sandbox 镜像，并支持固定版本升级和回滚。

### 开始使用

- 首次登录后，请打开**设置**，分别为所需模式配置 API 密钥、API 类型和模型。
- 使用宿主机上的搜索或模型服务时，请填写容器能够访问的地址，不要使用容器自身的 `127.0.0.1`。
- 点击**我知道了**后，本账号将确认此版本；仅关闭公告只会在当前页面临时隐藏。
